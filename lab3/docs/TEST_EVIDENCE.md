# Lab 3 — Bằng chứng kiểm thử (KAT, ctest, test âm tính, môi trường)

Tài liệu này mô tả các file log dùng làm bằng chứng cho báo cáo và **lệnh chính xác để tạo ra chúng**, để log Windows và Ubuntu có cùng nội dung và cùng định dạng.
Mọi lệnh gõ trực tiếp (bash / PowerShell); chạy từ thư mục `lab3`.

## 1. Các file log

| File (trong `lab3/output/<os>/`) | Nội dung |
|---|---|
| `kat_<os>_<compiler>.txt` | `rsatool --kat kat/vectors.json`: PASS/FAIL từng vector (124) và tổng kết |
| `ctest_<os>_<compiler>.txt` | `ctest` (3 test: unit, KAT, CLI end-to-end) kèm phiên bản compiler/CMake/thư viện và tóm tắt Catch2 |
| `negative_<os>_<compiler>.txt` | Các phép thử fail-closed của CLI (sửa ciphertext/tag/header, sai khóa, sai label, mã hóa hỏng, khóa không hỗ trợ...) kèm mã thoát |
| `env_<os>.txt` | Commit, SHA-256 của file KAT, phiên bản compiler/thư viện, phần cứng, hệ điều hành |

`<os>` = `windows` hoặc `ubuntu`; `<compiler>` = `mingw`, `msvc` hoặc `gcc`.

## 2. Nguồn của bộ KAT (chính thức)

`kat/vectors.json` được sinh bởi `scripts/make_kat.py` từ hai nguồn chính thức, chép **nguyên văn** (không sửa tay). Chi tiết ở `kat/SOURCES.md`:

- RSAES-OAEP RSA-3072, SHA-256, MGF1-SHA-256, có label: **Project Wycheproof** (C2SP), `testvectors_v1/rsa_oaep_3072_sha256_mgf1sha256_test.json` (37 vector: 18 hợp lệ, 19 phải bị từ chối).
- AES-256-GCM: **NIST CAVP** (CAVS 14.0), `gcmEncryptExtIV256.rsp` và `gcmDecrypt256.rsp` trong `gcmtestvectors.zip` (75 ca mã hóa + 12 ca xác thực phải thất bại).

## 3. KAT và `ctest`

```bash
cd lab3
mkdir -p output/ubuntu
mkdir -p build_ubuntu_gcc && cd build_ubuntu_gcc
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build .
cd ..
T=./build_ubuntu_gcc/rsatool
{ echo "== Known Answer Tests: rsatool (Ubuntu 24.04, GCC) =="; echo "date : $(date -u +%Y-%m-%dT%H:%M:%SZ)"; echo "git  : $(git rev-parse --short HEAD)"; echo "kat  : kat/vectors.json  sha256 $(sha256sum kat/vectors.json | cut -c1-64)"; echo; $T --kat kat/vectors.json; echo "[exit code: $?]"; } 2>&1 | tee output/ubuntu/kat_ubuntu_gcc.txt
cd build_ubuntu_gcc
{ echo "== ctest: GCC on Ubuntu 24.04 (Release) =="; echo "date : $(date -u +%Y-%m-%dT%H:%M:%SZ)"; echo "git  : $(git rev-parse --short HEAD)"; echo "g++  : $(g++ --version | head -1)"; echo "cmake: $(cmake --version | head -1)"; echo "cryptopp: $(dpkg -s libcrypto++-dev | grep ^Version)"; echo "nlohmann-json: $(dpkg -s nlohmann-json3-dev 2>/dev/null | grep ^Version)"; echo "catch2  : $(dpkg -s catch2 2>/dev/null | grep ^Version)"; echo; ctest --output-on-failure; echo; echo "-- unit tests (Catch2) summary:"; ./rsa_tests | tail -3; } 2>&1 | tee ../output/ubuntu/ctest_ubuntu_gcc.txt
cd ..
```

Kết quả mong đợi: `Summary: 124 tests, 124 passed, 0 failed` và `100% tests passed, 0 tests failed out of 3`.

## 4. Test âm tính (fail-closed)

Dán nguyên khối sau (tự tạo thư mục tạm `neg_tmp`, ghi log vào `output/ubuntu/negative_ubuntu_gcc.txt`). Đổi `T`, `PY`, `OUT` cho hệ điều hành khác,
ví dụ Windows (Git Bash): `T=./release/windows/rsatool_mingw.exe; PY=python; OUT=output/windows/negative_windows_mingw.txt`.
Cần `openssl` (dòng lệnh) cho phần I và K; Git Bash trên Windows và Ubuntu đều có sẵn.

```bash
cd lab3
T=./build_ubuntu_gcc/rsatool; PY=python3; OUT=output/ubuntu/negative_ubuntu_gcc.txt
TAMPER="$PY scripts/tamper.py"
mkdir -p neg_tmp output/ubuntu
W=neg_tmp
{
echo "== Lab 3 negative tests (fail-closed evidence) =="
echo "tool : $T"
echo "date : $(date -u +%Y-%m-%dT%H:%M:%SZ)"
echo "git  : $(git rev-parse --short HEAD 2>/dev/null)"
echo
run() { echo "+ $*"; "$@"; echo "[exit code: $?]"; echo; }
absent() { test -e "$1" && echo "RESULT: $1 WRITTEN (BAD)" || echo "RESULT: no output file written (good)"; echo; }

echo "################ 0. Setup (test keys generated by rsatool; test data)"
run $T keygen --pub $W/pub.pem --priv $W/priv.pem
run $T keygen --pub $W/other_pub.pem --priv $W/other_priv.pem
printf 'Lab 3 short message for direct RSA-OAEP' > $W/short.txt
head -c 5000 /dev/urandom > $W/long.bin
run $T encrypt --in $W/short.txt --pub $W/pub.pem --out $W/short.ct --verbose
run $T encrypt --in $W/long.bin --pub $W/pub.pem --out $W/long.ct --verbose
run $T encrypt --in $W/short.txt --pub $W/pub.pem --out $W/short_l.ct --label ctx-A
run $T encrypt --in $W/long.bin --pub $W/pub.pem --out $W/long_l.ct --label ctx-A

echo "################ A. Positive controls (must succeed, exit code 0)"
run $T decrypt --in $W/short.ct --priv $W/priv.pem --out $W/short.dec
run cmp $W/short.txt $W/short.dec
run $T decrypt --in $W/long.ct --priv $W/priv.pem --out $W/long.dec
run cmp $W/long.bin $W/long.dec
run $T decrypt --in $W/long_l.ct --priv $W/priv.pem --out $W/long_l.dec --label ctx-A
run cmp $W/long.bin $W/long_l.dec

echo "################ B. Altered RSA ciphertext (direct mode) -> decryption fails"
run $TAMPER --in $W/short.ct --out $W/short_bad.ct --mode flip-direct
run $T decrypt --in $W/short_bad.ct --priv $W/priv.pem --out $W/b.out
absent $W/b.out

echo "################ C. Altered AES-GCM ciphertext (hybrid) -> tag failure"
run $TAMPER --in $W/long.ct --out $W/long_bad.ct --mode flip-payload
run $T decrypt --in $W/long_bad.ct --priv $W/priv.pem --out $W/c.out
absent $W/c.out

echo "################ D. Altered authentication tag"
run $TAMPER --in $W/long.ct --out $W/long_tag.ct --mode flip-tag
run $T decrypt --in $W/long_tag.ct --priv $W/priv.pem --out $W/d.out
absent $W/d.out

echo "################ E. Wrong private key (direct and hybrid)"
run $T decrypt --in $W/short.ct --priv $W/other_priv.pem --out $W/e1.out
absent $W/e1.out
run $T decrypt --in $W/long.ct --priv $W/other_priv.pem --out $W/e2.out
absent $W/e2.out

echo "################ F. Wrong or missing OAEP label (direct and hybrid)"
run $T decrypt --in $W/short_l.ct --priv $W/priv.pem --out $W/f1.out --label wrong
absent $W/f1.out
run $T decrypt --in $W/short_l.ct --priv $W/priv.pem --out $W/f2.out
absent $W/f2.out
run $T decrypt --in $W/long_l.ct --priv $W/priv.pem --out $W/f3.out --label wrong
absent $W/f3.out
run $T decrypt --in $W/long_l.ct --priv $W/priv.pem --out $W/f4.out
absent $W/f4.out

echo "################ G. Tampered envelope header or container"
for m in flip-header-iv flip-wrapped-key change-modulus add-header-field bad-header-len bad-magic truncate; do
  run $TAMPER --in $W/long.ct --out $W/g_$m.ct --mode $m
  run $T decrypt --in $W/g_$m.ct --priv $W/priv.pem --out $W/g_$m.out
  absent $W/g_$m.out
done
run $TAMPER --in $W/short.ct --out $W/g_direct_modulus.ct --mode change-modulus
run $T decrypt --in $W/g_direct_modulus.ct --priv $W/priv.pem --out $W/g_direct_modulus.out
absent $W/g_direct_modulus.out

echo "################ H. Incorrect encoding of the ciphertext file"
run $T encrypt --in $W/long.bin --pub $W/pub.pem --out $W/long.hex --encode hex
run $T decrypt --in $W/long.hex --priv $W/priv.pem --out $W/h_ok.out --encode hex
run cmp $W/long.bin $W/h_ok.out
run $T decrypt --in $W/long.hex --priv $W/priv.pem --out $W/h1.out
absent $W/h1.out
printf 'zz-not-hex' > $W/bad.hex
run $T decrypt --in $W/bad.hex --priv $W/priv.pem --out $W/h2.out --encode hex
absent $W/h2.out
printf '*****' > $W/bad.b64
run $T decrypt --in $W/bad.b64 --priv $W/priv.pem --out $W/h3.out --encode base64
absent $W/h3.out
run $T decrypt --in $W/long.ct --priv $W/priv.pem --out $W/h4.out --encode base32
absent $W/h4.out

echo "################ I. Unsupported key sizes"
run $T keygen --bits 2048 --pub $W/p2048.pem --priv $W/k2048_rsatool.pem
run $T keygen --bits 3071 --pub $W/p3071.pem --priv $W/k3071.pem
openssl genpkey -algorithm RSA -pkeyopt rsa_keygen_bits:2048 -out $W/k2048.pem 2>/dev/null
openssl pkey -in $W/k2048.pem -pubout -out $W/pub2048.pem
run $T encrypt --in $W/short.txt --pub $W/pub2048.pem --out $W/i1.ct
absent $W/i1.ct
run $T decrypt --in $W/short.ct --priv $W/k2048.pem --out $W/i2.out
absent $W/i2.out

echo "################ J. Key and file errors"
run $T encrypt --in $W/missing.txt --pub $W/pub.pem --out $W/j1.ct
run $T encrypt --in $W/short.txt --pub $W/missing.pem --out $W/j2.ct
run $T encrypt --in $W/short.txt --pub $W/priv.pem --out $W/j3.ct
run $T decrypt --in $W/short.ct --priv $W/pub.pem --out $W/j4.out
printf -- '-----BEGIN PUBLIC KEY-----\nAAAA\n-----END PUBLIC KEY-----\n' > $W/broken.pem
run $T encrypt --in $W/short.txt --pub $W/broken.pem --out $W/j5.ct
run $T encrypt --in $W/short.txt --pub $W/pub.pem --out $W/short.ct
run $T keygen --pub $W/pub.pem --priv $W/priv.pem

echo "################ K. Interoperability: OpenSSL decrypts a Crypto++ RSA-OAEP ciphertext (positive control)"
run $TAMPER --in $W/short_l.ct --out $W/short_l.payload --mode extract-payload
LABELHEX=$(printf ctx-A | od -An -v -tx1 | tr -d '[:space:]')
echo "+ openssl pkeyutl -decrypt -inkey priv.pem -pkeyopt rsa_padding_mode:oaep -pkeyopt rsa_oaep_md:sha256 -pkeyopt rsa_mgf1_md:sha256 -pkeyopt rsa_oaep_label:<hex of ctx-A>"
openssl pkeyutl -decrypt -inkey $W/priv.pem -in $W/short_l.payload -out $W/k.out -pkeyopt rsa_padding_mode:oaep -pkeyopt rsa_oaep_md:sha256 -pkeyopt rsa_mgf1_md:sha256 -pkeyopt rsa_oaep_label:$LABELHEX
echo "[exit code: $?]"; echo
run cmp $W/short.txt $W/k.out

echo "################ L. A broken Known Answer Test file must not report success"
printf '[ {"name": "x"' > $W/bad_kat.json
run $T --kat $W/bad_kat.json
echo "== end =="
} 2>&1 | tee "$OUT"
```


## 5. Môi trường

```bash
cd lab3
mkdir -p output/ubuntu
F=output/ubuntu/env_ubuntu.txt
{
  echo "== commit =="; git rev-parse HEAD
  echo "== kat sha256 =="; sha256sum kat/vectors.json
  echo "== compiler / cmake / libraries =="
  g++ --version | head -1
  cmake --version | head -1
  dpkg -s libcrypto++-dev | grep -E "^Version"
  dpkg -s nlohmann-json3-dev | grep -E "^Version"
  echo "== cpu =="; lscpu | grep -E "Model name|^CPU\(s\)|Thread|Core|MHz"; lscpu | grep -qw aes && echo "AES-NI: yes (aes flag present)"
  echo "== governor =="; cat /sys/devices/system/cpu/cpu0/cpufreq/scaling_governor 2>/dev/null
  echo "== ram =="; free -h
  echo "== os =="; lsb_release -d; uname -a
  echo "== disk =="; lsblk -d -o NAME,ROTA,SIZE,MODEL
} > "$F"
cat "$F"
```

Ghi chú về SHA-256 của `kat/vectors.json`: trên Windows git có thể đổi xuống dòng (CRLF) nên hash khác Ubuntu dù nội dung giống nhau; so sánh hash của bản LF: `git show HEAD:lab3/kat/vectors.json | sha256sum`.
